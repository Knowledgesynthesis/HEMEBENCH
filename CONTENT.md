# Maintaining clinical content

| Module | Practice decision |
| --- | --- |
| Peripheral smear | Identify the circled cell or platelet in a second blood film using size, nucleus and granules. |
| CBC patterns | Interpret absolute counts and red-cell indices against the selected adult laboratory interval. |
| Anemia patterns | Combine MCV, the marrow response and clinical context to choose a mechanism or test. |
| Coagulation | Use the bleeding history, screening times and additional tests to distinguish possible causes. |
| Flow cytometry | Interpret markers on the reported gated population and decide whether the findings establish lineage or support further testing. |
| Molecular findings | Interpret variants with morphology, cytogenetics, treatment setting and the named classification framework. |
| Integrated cases | Use successive findings to choose the next test, interpret the result and act on urgency. |

## Updating an exercise

1. Read the cited guideline, reference laboratory entry or primary study and check for updates. Record the applicable adult population, units, assay and classification edition in the exercise when these change the answer.
2. Check that each synthetic finding fits the case. Verify derived indices, absolute counts and decision thresholds. Include the findings needed to distinguish two plausible choices.
3. Explain the specific clue behind the correct answer and the assumption behind each distractor. Place the source beside the feedback. Use a descriptive image alternative and keep the answer out of the question heading.
4. Check the glossary and the corresponding mixed-review question when a threshold, term or recommendation changes. Run the regression suite and read the rendered answer and citation as a learner would.

Module checks record completion of the practice task. Mixed review records first answers separately. These measures describe performance on the included items. HemeBench has no validated clinical competency assessment.
